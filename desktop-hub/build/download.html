Catnmice Game Hub

Play the Catnmice library on Windows. Choose offline packs during setup, or join the same online rooms as browser players.

Download for Windows x64

The launcher checks GitHub for updates to the hub and your installed games automatically. If you use an earlier preview with updates disabled, run this installer once to turn them on.

Windows may show “Unknown publisher” when you open the installer.
