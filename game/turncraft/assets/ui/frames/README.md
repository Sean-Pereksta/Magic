# Faction HUD frame artwork

These local assets are used by `game/turncraft/faction-hud.css`. They were generated with the built-in image generation tool (not the API/CLI fallback), then uniformly resized to 1024×1024 and encoded as WebP with the transparent alpha channel retained. No existing game artwork was replaced.

Final shipped paths:

- `game/turncraft/assets/ui/frames/frontier.webp`
- `game/turncraft/assets/ui/frames/ascendant.webp`
- `game/turncraft/assets/ui/frames/brood.webp`

Use a 160-pixel nine-slice border. The center is transparent, and CSS decorations do not accept pointer events.

## Final prompts

### frontier

Use case: stylized-concept. Asset type: production RTS HUD panel frame, not a mockup or screenshot. Create one square 1024x1024 ornamental rectangular frame for nine-slice UI rendering. Orthographic flat front view, symmetrical four corners, continuous straight border rails. Keep all artwork inside an outer 128-pixel rim; the central 768x768 square must be completely empty and genuinely transparent. Outside the frame also transparent. Extremely legible at small scale, broad readable material shapes, fine texture secondary. Corners may be richer but no oversized projections. No text, letters, digits, symbols resembling text, labels, buttons, screens, portraits, units, scenery, logos, watermark, fake checkerboard or opaque backing. This is a final usable transparent bitmap interface border, clean polished sci-fi strategy game art. Faction: Frontier Directorate. Rugged industrial military command console. Angular beveled gunmetal and dark navy armor plates, brushed steel, carefully placed copper fasteners and hazard-yellow notches. Small restrained cyan status lights inset into the steel corner assemblies. Solid, precise, utilitarian engineering; armored clipped corners and layered mechanical rails. Quiet darker inner edge to protect game text readability. Actual illustrated dimensional material, no diffuse glowing haze.
