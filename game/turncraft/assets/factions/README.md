# Turn Craft faction artwork

Generated with the built-in OpenAI `image_gen` tool on 2026-10-12. Each asset was generated independently, inspected at full size, and encoded as WebP at quality 88 without resizing. Generated originals remain in Codex generated-image storage; these optimized project copies are the production assets. All images are 1536 × 1024 pixels (3:2), RGB, and opaque.

The artwork follows the existing faction definitions in `game/turncraft.html` and leaves the bottom foreground dark enough for a text gradient. No typography is baked into the artwork.
