# Terrain and environmental animation

`terrain.js` renders all six existing battlefields, including Classic Frontier. It adds painted bitmap terrain atlases, true transparent prop animation sheets, and a shared combat effect atlas. Stable filenames and frame rectangles live in `assets/terrain-manifest.json` and `assets/effects-manifest.json`. Image-generation prompts and provenance live in `assets/terrain-prompts.json`; optimized final WebP files live on Cloudflare in the top-level `terrain/` and `effects/` folders. The repository contains the code and JSON metadata.

The ground atlases contain sixteen 256px cells: four floors, four paths, four raised/cliff textures, expansion flooring, cracks, ruins, and resource surroundings. The 512px transparent prop sheets contain four-frame mineral, gas and theme-specific ambient loops followed by four static decorations. Map themes use grass/debris, lava/embers, ice/snow, jungle/ferns, dunes/oasis, and industrial machinery. Combat effects use eight authored frames each for ballistic sparks, psionic energy, organic impacts, shields, explosions, and dust.

Resource loops hold each frame for 480 ms (1.92 seconds per cycle); ambient terrain loops hold each frame for 520 ms (2.08 seconds per cycle). Both run at half their former speed. Deterministic phase offsets keep neighboring props from moving in lockstep. Combat effect frames retain their existing 70 ms timing.

Permanent and temporary creep shimmer and the decorative construction glow also run at half speed. Creep growth, build progress and worker effects retain their original clocks.

`describeTile(tile, activeMapSeed, tileAt)` computes deterministic variant selection and eight-neighbor straight, convex, and concave corner masks without consuming simulation randomness. Cliff rims use the existing `blocked` property. Bitmap blending connects different floor types; obstacles keep a strong visible rim. Ordinary tile grid and repeated dashed lane squares are hidden once the richer atlases load. Missing sheets retain the existing durable artwork fallback.

The renderer caches eight-by-eight tile chunks at 32, 64, or 96 pixels per tile for Low, Medium, and High quality. A full medium field has twenty-four 512px chunks, about 24 MiB decoded. Geometry content, fixed map seed, atlas load version, and quality invalidate the cache; identical geometry in a new multiplayer snapshot reuses it. Resource amounts are never baked into the cache. Resource imagery and all environmental loops require current tile visibility, and empty nodes stop rendering. Static geography contains no units or current resource amounts. Ambient details stay below units, selection, commands, combat, and fog and do not add collision or targeting objects.

Runtime API: create a renderer with `TurncraftTerrain.createRenderer({baseUrl,effectsUrl})`; call `prepare({mapId,seed,terrain,width,height,quality,now})`, then `drawTile`, `drawAmbient`, and `drawResource`. Shared effects use `drawEffect(context,state,x,y,size,ageMs,{visible,quality,alpha,rotation,loop})`. `stats` reports asset loading, failures, chunk builds/hits, quality, seed, and draws. This state is cosmetic and is never serialized into gameplay snapshots.

The existing `drawShots` derives muzzle flashes and smoke accents from actual projectile times. Damage, shield, and destruction accents come from the sprite runtime's existing cosmetic event hooks. Fog checks apply every frame and the Low setting suppresses dust and ambient loops. Animations use render time and keep all construction, pathfinding, movement, combat, cooldown, balance, map locations and multiplayer mechanics authoritative and unchanged.

Run `python3 scripts/cache-visual-assets.py` before `node --test tests/terrain-runtime.test.cjs tests/terrain-assets.test.cjs` from this directory. Tests cover deterministic masks and seed zero, geometry preservation, static cache reuse/invalidation, resource depletion, fog gating, quality budgets, all six map asset files, dimensions, transparent alpha, and unique optimized bitmap content. Browser integration checks the actual decoder and map rendering alongside the broader animation runtime.
