HEARTHMOUSE — BROWSER EDITION
=============================

Open index.html in a modern desktop browser to play.

Controls
--------
WASD / Arrow Keys  Move (W always follows facing direction)
Mouse              Face and look
Hold left mouse    Drag-to-look fallback
Q / R              Turn left / right fallback
Shift              Sprint
Ctrl or C          Creep quietly
Space              Hop
Run over food      Pick it up automatically
E                  Settle in for dawn while inside the nest
1 / 2 / 3          Choose Cautious / Balanced / Desperate while in the nest
Escape             Release the mouse cursor

Mobile
------
Left stick         Move; pull gently to creep, farther to walk, fully to run
Right stick        Control facing direction and look
Rest Until Dawn    Appears at the bottom center while safely inside the nest
Colony Risk        Tap a policy in the nest panel

Colony orders
-------------
Cautious keeps autonomous mice close to home, makes them flee earliest, and
stops all ordinary foraging as soon as the nightly requirement is returned.

Balanced clears nearby rooms first and widens the search only as supplies run
out. It stops at the nightly requirement, except for a nearly completed safe
trip.

Desperate permits deep-room expeditions and a limited winter surplus. Mice
accept more exposure, but still seek mouse-sized shelter when a cat closes in.

The house changes every night. Food, doors, cover, noise, patrol focus, and
temporary passages can all shift. New rooms open throughout the 12-night
season, from the hallway and pantry to bedrooms, utility spaces, basement, and
garage.

Optional music
--------------
Place a file named backgroundsong.mp3 inside the audio folder. It will start
automatically at the beginning of each night. If the file is absent, the game
plays normally without background music.
