Play and host on Windows

Local Edition plays solo offline and lets a Windows x64 PC host a match for up to four players. Guests join in a browser using an Arcade listing or an invitation.

Find the Windows release Play in your browser

Use the Cat & Mouse release when available. Each release includes a Windows installer, portable ZIP, and SHA-256 checksums. Extract the portable ZIP before launching the game.

Join a host

Open the host’s invitation or pick their exact room in Live Lobbies. Enter a display name, choose eight build options, and select Ready.

Host a room

Open Local Edition and choose Multiplayer → Host Lobby. Set the room details and start the server. Share the invitation when the tunnel is ready, or use a public room to appear in the Arcade when discovery is available.

If guests cannot connect

Keep the host PC awake and connected. Retry the tunnel if verification fails and send guests the new invitation. When discovery is unavailable, share the invitation directly. Guests who lose their connection during a match should return to the original tab promptly to reclaim their seat.
