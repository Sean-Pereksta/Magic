How the draft assistant thinks

The recommendation score starts with draft value, then adjusts for roster need, stack opportunities, positional over-investment and player availability risk. It is intentionally transparent rather than pretending to know a single “correct” pick.

GREEN

Active with no current injury flag.

YELLOW

Questionable, limited, PUP or another situation worth monitoring.

RED

Out, IR, suspended or another major availability issue.

Suspension data varies by provider. Sleeper status/injury fields are used now; the provider adapter can merge a dedicated transactions/news API later.
