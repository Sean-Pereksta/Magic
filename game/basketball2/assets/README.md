# Menu artwork

`menu-hero.webp` is original menu artwork generated with the built-in imagegen tool, then encoded as WebP for delivery (1672 × 941, approximately 219 KB). It is used only by the menu. Player models, courts, basketball, animations, and gameplay effects continue to be generated by the existing game code.

The title, controls, labels, mode cards, tactical diagrams, and interactive UI are HTML/CSS/SVG, so they stay readable, responsive, and keyboard accessible. The artwork contains no baked-in interface text.

## Generation prompt

Use case: stylized-concept. Asset type: finished wide hero artwork for the menu of an arcade browser basketball game, Basketball 2. Primary request: create polished original basketball menu illustration, cinematic sports poster quality, for an interactive menu whose title and buttons are rendered separately in HTML. Composition: landscape panoramic 16:9 or wider. Keep the left 45 percent a restrained deep midnight navy negative-space field with faint court line texture, almost empty, so white menu text can be placed there. On the right 55 percent show three original adult basketball athletes in a dynamic coordinated team play: a blue-jersey ball handler low-dribbling forward, a blue-jersey teammate cutting toward a glowing hoop, a coral-jersey defender in athletic defensive stance. Stylized athletic proportions, expressive confident silhouettes, premium illustrated 3D-meets-screenprint sports art, crisp forms and subtle grain, blue and coral accents, warm ivory basketball court lines. Integrate an orange basketball and a luminous hoop near the upper right. Use dramatic stadium rim lighting, strong depth, a tasteful sense of motion, navy shadows with cyan/coral highlights. Characters and ball must read clearly even as menu background artwork. Scene and athletes occupy right and lower-right, clear separation from left copy area. No text, no lettering, no typography, no logos, no watermark, no user interface, no buttons, no panels, no photo-real human faces. This is menu art only; do not create an entire UI screenshot.
